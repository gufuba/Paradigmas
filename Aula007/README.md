# Aula 07 — Expressões, Atribuição e Controle

## Paradigmas de Linguagens de Programação

Este repositório contém os materiais desenvolvidos e estudados durante a **Aula 07** da disciplina de **Paradigmas de Linguagens de Programação**.

A aula aborda conceitos relacionados à construção e avaliação de expressões, atribuição de valores e estruturas de controle presentes nas linguagens de programação.

---

## Conteúdos estudados

### 1. Expressões

- Expressões aritméticas
- Precedência de operadores
- Associatividade
- Ordem de avaliação
- Efeitos colaterais
- Sobrecarga de operadores

### 2. Conversões de tipos

- Conversões de tipos
- Widening
- Narrowing
- Coerção implícita
- Conversão explícita
- Perda de precisão
- Operações com diferentes tipos de dados

### 3. Expressões booleanas

- Valores booleanos
- Operadores relacionais
- Operadores lógicos
- Avaliação de expressões
- Avaliação de curto-circuito

### 4. Atribuição

- Comandos de atribuição
- Atribuição como expressão
- Atribuição com diferentes tipos
- Conversões durante a atribuição
- Operadores de atribuição

### 5. Estruturas de controle

- Estrutura sequencial
- Estruturas de seleção
- `if` e `else`
- `switch`
- Estruturas de repetição
- `for`
- `while`
- `do-while`
- Controle de fluxo

### 6. Outros conceitos

- `goto`
- Comandos protegidos
- Guarded Commands
- Problemas relacionados ao fluxo de controle
- Exemplos práticos em diferentes linguagens

## Objetivo da aula

Compreender como diferentes linguagens de programação trabalham com **expressões, operadores, conversões de tipos, atribuições e estruturas de controle**, observando também as diferenças de comportamento entre as linguagens.

A aula permite entender melhor como o código é avaliado e executado, principalmente em situações envolvendo precedência, tipos de dados, conversões e controle do fluxo de execução.
